# 🎂 Happy Birthday, Wu JinXue (Olivia)

A personal birthday tribute website — 12 interactive pages filled with photos, wishes, music, and love.

## ✨ Features

- **12 immersive slides** — Hero, 8 wish pages, friendship, growth, and a heartfelt final message
- **Auto-playing music** — 4 Joker Xue (薛之谦) songs that play automatically on matching slides
- **Snow & cherry blossom animations** — Falling particles with ambient floating orbs
- **Poetic bilingual text** — Every page in both Chinese and English
- **Responsive design** — Works beautifully on mobile, tablet, and desktop
- **Keyboard & touch navigation** — Arrow keys, swipe, or dot navigation

## 🛠️ Tech

- Vanilla HTML, CSS, and JavaScript
- No frameworks, no dependencies
- CSS animations, `scroll-snap`, `clamp()` fluid typography

## 🚀 Run Locally

```bash
python -m http.server 8080
# Open http://localhost:8080
```

Or just open `index.html` in any browser.
